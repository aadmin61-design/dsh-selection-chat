# DSH Selection Chat 1.4.1

为 DSH 原生划词菜单增加**侧边提问**，在右侧打开临时聊天。文本引用改用 DSH 原生功能，引用预览、编辑和发送均由宿主处理。

适用于 **DSH 0.2.2-rc.3**。独立插件，不依赖 Codex 或 codex-dots，不需要安装 Node、Python 或构建环境。DSH 0.2.1 用户请保留插件 1.3.0。

[下载安装包](https://github.com/aadmin61-design/dsh-selection-chat/releases/download/v1.4.1/dsh-selection-chat-1.4.1.zip) · [版本发布](https://github.com/aadmin61-design/dsh-selection-chat/releases) · [更新记录](CHANGELOG.md)

## 功能

在对话正文中选中文字，原生划词菜单中出现：

- **引用文本**：调用 DSH 原生引用，保留已有问题和附件。引用的展示、移除、编辑、草稿恢复和发送行为与 DSH 一致。
- **侧边提问**：新建临时侧边聊天，把选中文字交给侧栏的原生编辑器。输入问题后手动发送，不会自动调用模型。

菜单定位和选区处理复用 DSH。插件不再显示独立引用卡片，也不再修改消息发送方法。未设置单条文本截断；实际编辑和发送限制遵循 DSH。

侧栏使用原生聊天内容、编辑器、模型选择和权限界面。新增的菜单、标题栏、状态标签及保存按钮使用 DSH 主题变量，跟随明暗主题。标题显示“侧边对话”，附带“临时”或“已保存”状态，不显示分支创建成功提醒。

侧边聊天继承来源对话**最近已完成轮次**的上下文供模型理解，但侧栏隐藏继承的主对话内容，只显示新的交流。若还没有任何已完成轮次，请等首轮结束后创建。主对话与各个侧栏独立；发送前请检查侧栏的模型与权限，消息使用所选模型的额度。

## 临时聊天与保存

- 默认不进入左侧目录，不写入 DSH 会话日志。
- 点击标签的 **×**：取消并清理该临时聊天，包括正在生成的内容。清理失败会提示并有限重试。
- 折叠右侧栏、切换主对话或刷新页面：保留临时会话。退出或重启 DSH、卸载插件：丢弃未保存的临时会话。
- 回答结束或停止后点击 **保存**：将完整会话保存到来源对话所属的目录，并切换到这个长期会话。保存前需发送或清空未提交的问题、引用和附件，以免它们留在旧临时输入框中。
- 保存后关闭标签只关闭视图，从左侧目录仍可继续。继承上下文也保存在完整历史中，从左侧打开时可以查看。
- 来源目录已删除或不可用时会报错，不会改存其他目录。旧版创建的长期分支不会自动删除。

临时模式管理会话日志和生命周期；模型或工具产生的文件、上传附件仍按 DSH 规则保存，关闭会话不会删除项目文件。

## 安装与升级

1. 从 [Releases](https://github.com/aadmin61-design/dsh-selection-chat/releases/latest) 下载 `dsh-selection-chat-1.4.1.zip`。
2. 解压其中的 `dsh-selection-chat` 文件夹到固定位置，例如 `C:\dsh-plugins\dsh-selection-chat`。
3. 打开 DSH → 插件 → 添加插件，填写该文件夹的**绝对路径**，安装并启用。
4. 若提示重启，先保存需要保留的临时聊天并结束任务，再手动重启。插件详情应显示 `@local/dsh-selection-chat`、`v1.4.1`。

源码安装填写实际包含 `package.json`、`index.mjs`、`temporary.mjs`、`client.js` 和 `cordis.patch.yml` 的目录；不需要 `npm install`。链接安装后请保留原目录。

**升级**：先保存临时聊天，解压新包覆盖原插件目录，再手动重启 DSH。依赖被停用时，在插件详情重新启用。1.4.1 依赖新版原生引用模块，不能安装到 DSH 0.2.1。

同一窗口中仍有旧版引用缓存时，会出现一次恢复入口；点击“恢复到输入框”交给原生编辑器，或点击“丢弃”。如果旧引用曾在发送中，先检查历史确认是否已发送，再决定是否恢复。已交给原生编辑器的引用由 DSH 管理，不再保存在插件卡片中。

卸载使用 DSH 插件管理器。卸载后恢复原生“引用文本”菜单，已保存的长期聊天保留，未保存的临时聊天被清理。

## 手动验证

以下界面操作由用户完成，自动检查不会打开窗口或发送消息：

| 操作 | 预期结果 |
| --- | --- |
| 打开至少完成一轮的主对话，选中回答正文 | 出现一个菜单，含“引用文本”和“侧边提问”，没有两套重叠菜单 |
| 先在输入框写问题，再点击“引用文本” | 出现 DSH 原生引用，已有问题保留，不自动发送 |
| 划选多行或代码，添加和移除引用 | 显示及操作与 DSH 原生引用一致，选中的代码不会被执行 |
| 点击“侧边提问” | 右侧显示临时聊天和原生引用，左侧不新增会话；侧栏不显示主对话旧消息及创建提醒 |
| 切换明暗主题、调整侧栏宽度 | 菜单与标题栏跟随主题，正文与输入框保持原生布局 |
| 在侧栏补充问题并手动发送 | 消耗所选模型额度；引用和问题提交一次，回答显示在侧栏 |
| 创建两个侧栏，关闭其中一个标签 | 只清理被关闭的临时会话，另一个侧栏和主对话保留 |
| 折叠右侧栏、切换主对话再返回 | 原有临时会话仍可继续，不重复插入已接纳的引用 |
| 在目录 A 创建侧栏，回答结束且草稿清空后点击“保存” | 长期会话出现在目录 A，侧栏状态变为“已保存” |
| 保存后继续交流、关闭标签，再从左侧打开 | 保存前后内容均保留 |
| 存在未发送问题或引用时点击保存 | 提示先发送或清空草稿，内容保留在原输入框 |

如遇问题，请提供 DSH 精确版本、插件状态、问题发生在主对话还是侧栏，以及错误提示或截图。


```powershell
$env:ELECTRON_RUN_AS_NODE = '1'
try {
  & 'C:\Program Files\DSH\DeepSeek Harness.exe' --expose-internals scripts/host-check.cjs 'C:/Program Files/DSH/resources/app.asar/dsh' 2>&1 | Out-String
} finally { Remove-Item Env:ELECTRON_RUN_AS_NODE }
```

插件复用原生 `conversation.chat.text-interaction` 菜单槽位与 `inputActions.insertQuote`。临时会话沿用定向写句柄适配，左侧目录过滤临时 ID，侧栏按继承轮次隐藏旧历史。没有修改 DSH 安装文件。发行包不含 DSH 源码、账号、会话历史或本机检查数据。
